# Bases fixtures

`Tasks.base` and `First.md` are portable inputs for Obsidian and Crucible.
They exercise nested tags, formulas, sorting, a numeric summary and a kanban
view. They are not claimed to be output captured from Obsidian.

The installed Flatpak Obsidian wrapper launched the desktop app but did not
answer `help base:query` during implementation. A live Obsidian CLI comparison
therefore remains outstanding; the automated tests run without Obsidian.
